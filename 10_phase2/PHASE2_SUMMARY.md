## Reflection and module concepts

The core Unreal reflection markers were reviewed conceptually:

```cpp
UCLASS()
USTRUCT()
UENUM()
UPROPERTY(...)
UFUNCTION(...)
GENERATED_BODY()
```

- `UObject` is the base engine object type that participates in Unreal's object and reflection systems.
- `AActor` is a world object that can be placed or spawned and can own Components.
- `*.generated.h` is generated by Unreal Header Tool and is included last in a reflected header.
- `Public/` exposes headers to other Unreal modules; `Private/` contains module-internal implementation.
- Unreal modules are build units declared with `.Build.cs`; they are not C++20 language modules.
